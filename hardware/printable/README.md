# 3Dプリント用・裏面取付フレーム（寸法未確認の試作）

STLはmm単位。**現物の穴位置を反映した完成品ではありません。** `params.json` のパネル穴間隔280×120mm、穴径3.4mm、基板穴間隔56×46mmは仮値です。画像から穴座標を決めてはいません。STLファイル名のDRAFTもこの意味です。

## 部品構成

320×160mmを仮定したフレームを左右2分割しました。右半分には基板取付台とケーブル保持穴があります。長辺・短辺の連結穴は同じ端からの距離にそろえ、共通の連結部品で横・縦を組み替えます。

| ファイル | 2枚構成に必要な数 | 役割 |
|---|---:|---|
| `carrier-left-DRAFT.stl` | 2 | 左半分の開放フレーム |
| `carrier-right-DRAFT.stl` | 2 | 基板取付台付き右半分 |
| `split-splice-DRAFT.stl` | 4 | 各フレーム中央の上下をつなぐ部品 |
| `panel-link-DRAFT.stl` | 2 | パネル間の連結。縦横共通 |
| `board-spacer-DRAFT.stl` | 8 | 基板用スペーサー（仮高さ10mm） |
| `panel-spacer-DRAFT.stl` | 8 | パネルとフレームの間（仮高さ8mm） |

各半分は仮寸法156×152×5mm。印刷範囲にはブリム等の余裕も必要です。分割継ぎ目には位置決め機構を設けず、上下2本のスプライスとM4ねじ・座金・ナットで接続します。連結穴は4.5mm、連結部品は厚さ6mmです。基板を固定する長穴の調整範囲は横方向のみで、縦方向の穴間隔は実測で変更してください。

## 印刷前に変更する寸法

1. パネル外形と、左右・上下の既存取付穴間隔を測る。この初版は中心対称な4穴を仮定。非対称・異なる穴数なら生成コードの穴座標も変更が必要。
2. パネル穴のねじ径・有効深さを確認し、通し穴径とねじ長さを決める。仮の3.4mm穴はM3適合を保証しない。
3. S3基板の穴間隔を測る。この初版は中心対称な4穴を仮定。外形寸法から穴間隔を推測しない。
4. 背面突起、裏側ピン、USB・電源・リボン・操作スイッチの位置を確認し、スペーサー高さ・基板位置を調整する。
5. `params.json` を変更して再生成する。穴位置変更でレールから外れると生成は停止する。

再生成例（プロジェクトルートから）：

```powershell
python -m venv tmp/cad-venv
& tmp/cad-venv/Scripts/python.exe -m pip install trimesh shapely mapbox-earcut
& tmp/cad-venv/Scripts/python.exe hardware/printable/generate.py
```

## 組立と確認

平らな面をベッドに置いて印刷する形状です。材料・積層・充填条件はプリンターと使用温度に合わせて決め、まずスペーサー1個で穴の通りを確認してください。ねじ・座金・ナットは市販金属品を使用。プリント穴に直接ねじを切る方式ではありません。基板固定には絶縁スペーサーを使い、金属座金が周辺のパターンに触れないことを確認します。

パネル側のねじ長さは取付厚と有効深さから決めます。ねじの締付けでフレームやパネルを反らせず、前面の高さをそろえます。電源を切って組立て、通電時の温度と反り、操作時のずれを確認します。耐荷重・耐熱・実物適合は未検証で、床・卓上の支持枠で支える試作向けです。吊り下げには使用しません。

`preview.svg` は生成形状の上面図。`stl-draft/verification.json` は再読込したSTLの閉じたメッシュと面向きの検査結果で、機械強度の検証ではありません。
