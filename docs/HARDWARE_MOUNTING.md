# パネル裏面の固定・パネル間の簡易連結案

検討日: 2026-10-03。対象は本プロジェクトのP5・64×32パネルとSeengreat RGB Matrix HUB75 S3、各パネルにコントローラー1台を持つ構成。以下は試作案で、耐荷重や温度は未検証。

## 推奨する構成

**各パネルに独立した裏面取付板を設け、隣接パネルの取付板を2本の平金具で橋渡しする。** 基板の固定とパネルの連結を分けると、配線済みの単体ユニットを保ったまま縦・横に組み替えられる。

```text
側面（概念図）
LED面｜パネルの既存取付ボス｜スペーサー｜裏面取付板｜絶縁スペーサー｜S3基板

横連結・背面（概念図。実際の左右は正面と逆になる）
┌────────────┐ ┌────────────┐
│ 取付板 ───────平金具─────── 取付板 │ ← 接合辺の上寄り
│   S3基板     │ │    S3基板    │
│ 取付板 ───────平金具─────── 取付板 │ ← 接合辺の下寄り
└────────────┘ └────────────┘
```

縦連結では接合辺の左寄り・右寄りに2本置く。1本だけでは継ぎ目を軸に回転しやすい。取付板の連結穴は四辺に用意するが、板や金具がパネル外形からはみ出して継ぎ目を広げないようにする。

## 各パネルの裏面への固定

第一候補は、既存取付ボスを利用して絶縁性の取付板をねじ止めする方法。

- 板の材料は加工しやすい3～5mm程度の合板を試作候補にする。寸法・厚さは取付ボス間隔とたわみで決定し、全面を塞がず、必要な取付点を結ぶ形にする。
- パネル側は利用できる既存取付点を分散して使う。4点が使えるなら4点固定を基本とする。パネルPCBや樹脂枠への新規穴開けは行わない。
- 基板は既存取付穴と絶縁スペーサーで板に固定する。スペーサーは高さ8～12mm程度から仮合わせし、裏側ピン・部品が板に触れない高さに調整する。
- パネル側ねじの径・ピッチ・長さは現物に合わせる。特に有効ねじ深さを確認し、板厚・座金・スペーサーの厚さを加味する。M3と決め打ちしない。
- USB-C、ジョグスイッチ、BOOT/ENの操作空間とケーブルの曲げ空間を確保する。アンテナ付近を金属板や金具で覆わない。
- ケーブルを板の穴と結束バンドで保持し、USB/HUB75コネクターに引っ張り荷重を掛けない。信号・電源は各パネル内で完結させる。

メーカー資料ではS3基板の外形は65×57.5mm、取付穴径は2.5mmで、取付穴はM2.5と記載されている。穴中心座標と現物revisionは別途照合する。[メーカーWiki](https://seengreat.com/wiki/214/rgb-matrix-hub75-s3)

P5・64×32から想定する表示寸法は320×160mmだが、外形・厚さ・取付穴位置は手元のパネルの実測を優先する。

### さらに簡単に仮固定する場合

小さな樹脂ケースへ基板をねじ止めし、ケースを再使用できる結束バンド2本でパネルの丈夫な枠へ固定する。バンドを通せる枠構造がある場合に限る。部品・はんだ面・コネクターへバンドを直接掛けず、LED面へ回さない。

面ファスナーを使うなら、ケースと平らな取付板の間に用いる。凹凸のあるパネル背面へ直接貼る方式は接着面積が取りにくく、主固定にはしにくい。

## パネル同士の連結

| 方法 | 組み替え | 向く用途 | 判断 |
|---|---|---|---|
| 取付板＋平金具2本＋手回しねじ | 容易 | 縦横を切り替える試作 | 推奨。穴位置を共通化できる |
| 2枚共通の背板へ既存穴で固定 | 背板交換が必要 | いつも同じ配置 | 最も単純。面の段差を抑えやすい |
| 既存ボスへ平金具を直接固定 | 穴位置次第 | まず2枚だけ連結 | 取付板不要。ただしボスへの横荷重や締付高さに注意 |
| 枠へ結束バンドで連結 | 切断・交換が必要 | 卓上の位置確認 | 仮止め向け。段差やねじれを抑えにくい |
| 磁石だけで連結 | 非常に容易 | 吸着位置の仮合わせ | ずれ・剥離があるため主連結には選ばない |

平金具は幅15～25mm・厚さ約2mmを試作の出発点とし、長さは穴間距離に合わせる。これは耐荷重仕様ではない。幅広い座金とナットを用い、取付板を局所的に潰さない。金具の角・バリは処理する。

各平金具に各パネル側1本ずつ、計4本の連結ねじを基本とする。手回しねじと抜けないナットを組み合わせると、パネル側の浅いねじ穴を組み替えのたびに使わずに済む。位置決め側を丸穴、調整側を短い長穴にすると、実測誤差を吸収しやすい。両側を長穴にすると位置が定まりにくい。

連結時は柔らかい平面上でLED突起に荷重が集中しないよう支持し、表示面をそろえてから締める。背面高さの差はスペーサーで合わせ、ねじで無理に引き寄せない。

2枚を立てて使う際は、共通の脚または外枠で支える。枚数が増えた場合はレールや外枠へ各パネルを固定し、連結金具だけで全体重量を支えない。吊り下げ用途はこの簡易案の検証対象外で、支持枠と落下防止を別に設計する。

## 最初の2枚で用意するもの

- パネルごとの裏面取付板2枚と、既存穴に合うねじ・スペーサー・座金。
- 基板用M2.5ねじ・絶縁スペーサー・ナット。数量は現物の利用可能な穴数に合わせる。
- 連結用平金具2本と、取付板用の手回しねじ・座金・ナット計4組。ここはM4を設計候補にできるが、パネル側ねじ規格とは別。
- ケーブル保持用結束バンド。固定穴に通す方式を優先。

取付板と連結金具の加工前に、パネル外形・厚さ・重量、既存穴中心座標、ねじ規格と有効深さ、背面最大突起高さ、基板穴位置、ケーブルを挿した状態の占有範囲を測る。現時点では穴座標を確定した加工図は作らない。

## 試作で確認すること

1. まず1枚で裏面ユニットを作り、ねじ先端の干渉、基板裏の接触、操作性を確認。
2. 2枚を横・縦に連結し、継ぎ目の隙間・面の段差・ねじれを確認。
3. 使用する脚や支持枠に載せ、ケーブルの引っ張りやスイッチ操作で動かないことを確認。
4. 想定する明るさで連続運転し、通風、板の変形、接着部の浮き、ねじの緩みを確認。

固定・連結は機械的な構成で、現在の各パネル独立電源・独立コントローラー構成を維持できる。
